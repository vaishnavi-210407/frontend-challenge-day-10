# 🛍 Product Filter UI

A simple and responsive Product Filter UI built using HTML, CSS, and JavaScript.

## 🚀 Features
- Product search functionality
- Category filtering
- Responsive design
- Dynamic product rendering
- Clean UI

## 🛠 Tech Stack
- HTML
- CSS
- JavaScript

## 📂 Project Flow
1. Created products data array
2. Rendered products dynamically
3. Added category filter buttons
4. Implemented search functionality
5. Added responsive styling

## 🎯 Learning Outcome
- Improved DOM manipulation skills
- Better understanding of array filtering
- Practiced dynamic rendering
- Learned event handling
